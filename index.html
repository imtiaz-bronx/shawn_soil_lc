Does the tree hold the slope?

Set the conditions of a hillside, choose a species Nuru plants or a root cohesion value, and see the modeled Stability Index for that slope. A slope is modeled as stable at SI ≥ 1.5. The change is measured against the same slope with no vegetation.

How this is calculated
C = (Cr + Cs) / (h · ρs · g)
SI = [ C + cosθ·(1 − W·r)·tanφ ] / sinθ

ρs (wet soil density) is fixed at 1800 kg/m³ and g at 9.81 m/s², as in the workbook. Every other term is set above. C is the dimensionless combined cohesion; SINMAP treats a cell as stable at SI ≥ 1.5. This is a single-slope calculator, not a basin-wide model run: it answers what the index would be for one hillside under the conditions you set, not where in the watershed planting helps most.

Formula and default values from the Nuru Cohesion_SI workbook. Species root cohesion after Zegeye et al. (2018): Gravillea robusta 400, Eucalyptus camaldulensis 1100, Acacia decurrens 3900 N/m². Prototype for review.
