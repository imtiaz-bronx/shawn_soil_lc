Stability Index Mapping (SINMAP) Calculator for Agroforestry Treatment

Can tree planting increase slope stability?

This calculator evaluates slope stability using the SINMAP algorithm (see the SINMAP manual), which includes a root cohesion parameter Cr (N/m²). Cr can be changed according to the chosen plant species, and the calculator returns the Stability Index (SI).
